# 4 迁移校验

本文件负责单表迁移后的必要核验，回答“数据是否按已确认规则迁对了”。

## 4.1 输入

- 已确认字段映射和迁移范围；
- 源键、目标键及数量关系；
- 必填字段、固定值和关键业务字段；
- DataX 实际退出状态和写入统计。

数据库查询须取得对应授权。没有执行查询时，输出 `未执行`，不得用推测结果代替。

## 4.2 校验内容

- 字段数按已确认映射判断，不机械比较源表和目标表的物理列数；
- 记录数按迁移范围和已确认关系判断，存在过滤、去重或展开时不要求简单相等；
- 重复数按已确认键统计，并注明是重复组数还是多余记录数；
- 必填字段不存在空值；
- 默认值和固定值符合映射规则；
- 关键业务字段与源端转换结果一致；
- DataX 日志条数只作运行参考，不替代数据库对账。

统计沿用当前 mapping 和前检口径，注明来源、迁移范围、数据阶段、单位及所用键。多来源按已确认覆盖规则计算最终数量；只有来源内部键唯一且无其他过滤时，双源并集数量才可按“两源数量之和减去重叠键数”计算。总写入次数不等于最终目标记录数。

跨库核验 SQL 标明每段执行库。条数差仅用于发现异常，应按已确认键定位缺失、额外或重复记录，不能由差值直接断言缺失哪些记录。目标值应与胜出来源的已确认转换结果一致，包括整条覆盖时的空值。

## 4.3 输出

校验结束只输出一张表，标题为“源表与目标表校验结果”。

```text
源表与目标表校验结果

序号 | 校验项       | 源表 | 目标表 | 校验结果
-----+--------------+------+--------+---------
1    | 映射字段数量 | 11   | 15     | 符合预期
2    | 总记录数     | 87   | 87     | 符合预期
3    | 重复记录数   | 0    | 0      | 符合预期
4    | 必填字段     | 0    | 0      | 符合预期
5    | 固定值       | —    | 0      | 符合预期
```

- 标题与表格前后各留一个空行；
- 表头、分隔线和数据列必须对齐，不得挤在一起；
- 所有必要校验均放入同一张表，不追加复杂明细表；
- `未执行`、`查询失败`、`未取得` 均不得填写为 0 或判定通过；
- 失败详情通过人工核验 SQL 或日志查看；跨表校验由批量 Skill 编排；记录级留痕等新增能力由扩展 Skill 设计，所属主 Skill 实现。

## 4.4 完成条件

只有同时满足以下条件，才能报告 `数据迁移完成`：

- DataX 正常退出；
- 迁移失败条数为 0；
- 源表和目标表数量关系符合预期；
- 重复键、必填字段、固定值和关键业务字段检查通过。

必要校验全部通过时先报告 `迁移校验通过`。任一必要条件未满足，报告 `迁移校验失败` 或 `迁移执行失败`，并提供可直接粘贴的人工核验 SQL。
